# 🌐 Web Development Demo

A simple beginner-friendly HTML project created while learning the fundamentals of web development.

## 📌 About

This project demonstrates basic HTML structure and common elements such as:

- Headings
- Paragraphs
- Unordered lists
- Buttons
- Basic JavaScript interaction
- Responsive page setup

## 🛠️ Technologies

- HTML5
- CSS
- JavaScript

## 📁 Project Structure

```text
project-Deemo/
├── README.md
└── index.html
```

## ▶️ How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Explore the page and interact with the button.

You can also use **VS Code + Live Server** for local development.

This project was created to practice:

- Semantic elements
- Lists and buttons
- JavaScript event handling
- Organizing a small web project
